# COMPRESS-X

## Advanced Data Compression Analysis, Visualization & Benchmarking Platform

COMPRESS-X is an interactive data compression laboratory developed as a course project for CSI3019 - Advanced Data Compression Techniques.

The platform is designed to implement, analyze, visualize, and benchmark multiple lossless and lossy data compression techniques.

## Project Objectives

- Analyze the statistical characteristics of input data.
- Calculate entropy and data redundancy.
- Implement major lossless compression algorithms.
- Implement selected lossy compression techniques.
- Visualize the internal working of compression algorithms.
- Compare compression performance across different algorithms and datasets.
- Analyze the trade-off between compression ratio, computational cost, and reconstruction quality.
- Provide an interactive dashboard for experimentation and visualization.

## Planned Compression Techniques

### Lossless Compression

- Shannon-Fano Coding
- Huffman Coding
- Arithmetic Coding
- LZ77
- LZ78
- LZW

### Lossy Compression

- Scalar Quantization
- Vector Quantization
- LBG Algorithm
- DCT-based Image Compression
- Wavelet-based Compression
